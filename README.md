# Calculadora de Impostos Indiretos em Python

Este projeto é uma ferramenta simples via linha de comando para calcular tributos indiretos sobre o consumo no Brasil, simulando tanto o modelo tradicional quanto o novo modelo do IVA.

## 🚀 Funcionalidades

- **Cálculo de IVA (Por Fora):** Simulação da CBS (Federal) e IBS (Estadual/Municipal).
- **Cálculo de ICMS (Por Dentro):** Simulação do cálculo tradicional onde o imposto integra sua própria base de cálculo.

## 🛠️ Como Executar

Certifique-se de ter o Python 3 instalado em sua máquina. No terminal, execute:

```bash
python calculadora.py
```
